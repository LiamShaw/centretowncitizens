{{/* Generates the Cloudflare Pages _redirects file. Cloudflare Pages reads a file called _redirects from the root of the published site. Every URL the old Squarespace site published needs a permanent redirect to its new home, so that inbound links from council documents, press coverage and social media keep working. The map is generated from data/redirects.csv, which the export writes by pairing each old Squarespace path with the path its content now lives at. This template renders it as a Cloudflare _redirects file during the Hugo build, so the redirect map can never be left out of a deployment. The file is also regenerated and verified by tools/build_redirects.py and tools/check_coverage.py, which work from the built output and catch any page whose published path differs from the recorded one. */}} {{- $rows := slice -}} {{- with (index .Site.Data "redirects") -}} {{- range . -}} {{- $rows = $rows | append (dict "source" .source_path "target" .target_path) -}} {{- end -}} {{- end -}} {{- if not $rows -}} {{- errorf "data/redirects.csv is missing or empty. Run tools/export_squarespace.py before building." -}} {{- end -}} # Generated by the Hugo build from data/redirects.csv. Do not edit by hand. # Every URL the old Squarespace site published, redirected to its new home. /* {len $rows} redirects */ {{- range $rows }} {{ .source }} {{ .target }} 301 {{- end }}
